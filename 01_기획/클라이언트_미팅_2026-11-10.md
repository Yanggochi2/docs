# 클라이언트 미팅 정리 (2026-11-10)

> 클라이언트 7차 미팅 정리입니다. 노션 회의록(클라이언트 미팅 > 7차-11월10일화요일)을 옮겼어요.
>
> **핵심: 자동 생성 결과의 품질(인원 초과·쏠림·무리한 패턴)과 속도**를 고치고, 간호사 등록·공유 화면·OFF 표시를 다듬어요.

## 1. 완료 및 진행 현황

- 간호사 정보 수정 및 삭제: 구현 완료
- 엑셀 간호사 추가: 기능은 추가되었으나 **테스트 미진행**
- 테스트 병동 인원 상태: 현재 테스트 병동에 인원이 과도하게 배치되어 있음

## 2. 기능 추가 및 개선

- 새로운 사용자층: **간호조무사** 사용자층 추가
- 간호사 추가 유효성 검사 및 자동화
	- 입사 연도와 경력 불일치 방지
	- 입사 연도 입력 시 경력 자동 선택
	- 3개월 정도 경력 시 숙련도를 1~2로 자동 설정
- 공유 링크 뷰어 개선: 링크 안에서 **자신의 이름을 검색**해 본인 일정만 확인
- 수간호사 권한: 인력 상황에 따라 **강제로 OFF 배정**
- 근무 시스템: 남은 OFF **이월 처리 로직 확인**
- 대시보드: 데이터 시각화를 위한 **통계 그래프** 표시

## 3. 자동 생성 로직 개선

- 속도 최적화: 근무표 자동 생성 속도가 느려 개선 필요
- 패턴 수정: 특정 근무자에게 `DDEEN` 같은 무리한 패턴이 나오는 로직 개정
- 쏠림 현상 해결: 14일 등 특정 날짜에 데이(D) 근무가 너무 몰리는 현상 수정
- 인원 초과 방지: 전반적으로 배정 인원이 넘치는 현상(특히 데이) 해결
- 적정 인원수 매칭: 병동의 '적정 인원수 지표'에 맞춰 그날 필요한 인원만 정확히 채우도록 강화

## 4. UI 및 화면 표시

- OFF 표시 1: 근무표 **이름 옆에 남은 OFF 개수** 표시
- OFF 표시 2: 원래 남은 OFF가 있던 **마지막 열에는 총 OFF 수** 표시

## 확인 필요

- 간호조무사: 역할 값, 필요 인원(D7·E5·N5)에 포함하는지, 근무표에서 따로 표시하는지
- 경력 자동 숙련도: "3개월 정도"의 정확한 기준(개월 수)과 숙련도를 1·2 중 무엇으로 넣을지
- 강제 OFF: 수동 편집 + 셀 고정으로 충분한지, 재생성해도 유지되는 별도 기능이 필요한지
- 통계 그래프: 어떤 지표를 보여 줄지 (6차의 "근무표 작성에만 집중"과 함께 통계 메뉴는 유지하는 쪽으로 정리)
- "7·5·5"의 뜻은 6차에 이어 아직 확인 안 됨

# 주간 미팅 정리 (2026-10-20)

> 10-20 주간 회의 정리입니다. 노션 회의록에 **PM 미팅 > 4차-10월20일화요일**과 **클라이언트 미팅 > 4차-10월20일화요일** 두 곳에 같은 내용으로 올라가 있어 하나로 옮겼어요.
>
> 두 페이지는 "담당별 할 일" 표만 달라요. 클라이언트 미팅 쪽은 담당자 이름(민서·석찬·수혁·효주)으로, PM 미팅 쪽은 역할(백엔드·근무 짜기 화면 담당 등)로 적혀 있어요. 아래는 이름으로 적힌 쪽을 따랐어요.

## 총평

반 스텝은 나갔지만 진척이 너무 더뎌요. 다음 주까지는 확실히 한 스텝 전진할 것.

## 1. 협업 / 코드 리뷰

- 팀원 PR 승인·코멘트가 전부 0건이에요. 구두로 얘기한 건 기록이 안 남으므로 **PR에 코멘트로 남길 것** (AI 봇 리뷰 말고 사람 리뷰).
- 지금은 기능 개발보다 코드 리뷰가 더 중요해요. 남이 짠 코드를 읽는 연습을 해야 에러가 났을 때 고칠 수 있어요.
- 머지를 한 명이 전담하지 말고 서로 리뷰할 것.

## 2. 로그인 / 가입

- 흐름: 가입 신청 → 수간호사 승인 (이때 숙련도 등 입력)
- 1차로는 "로그인한 간호사만 근무 배정 가능" 구조를 유지. 가입을 안 하거나 늦게 하는 간호사 대응은 추후 고민.

> 이후 [클라이언트 미팅 (10-26)](클라이언트_미팅_2026-10-26.md)에서 로그인 기능 전부 제거로 바뀌었어요.

## 3. 근무 규칙 / 자동 생성 (가장 시급)

- **오프 15~16일 배정은 치명적인 문제.** 사실상 하루 일하고 하루 쉬는 구조예요.
- "3일 근무 후 무조건 오프"는 잘못된 규칙. 데이는 4~5일 연속도 가능하고, 연속 근무 제한은 나이트 기준으로 수정 중.
- 일별 인원 기준(데이 6 / 이브닝 5 / 나이트 3)과 실제 결과가 불일치함 (나이트 4명 배정 등). 기준 자체가 맞는지도 재확인 필요.
- 자동 생성 로직을 짜기 전에 **병동 근무·오프 규칙부터 확정**할 것.

## 4. 근무표 화면 (수간호사용)

- 가나다순 정렬은 안 됨. 순서는 ① 수간호사 ② 그다음 직급 간호사 ③ 이후 경력순으로 하고, **숙련도를 함께 표시**.
- 승인된 오프 신청이 일반 오프와 구분이 안 됨. "신청 → 승인된 오프" 표시가 필요함.
- 이미 확정된 달은 신청이 안 되므로 다음 달 기준으로 테스트할 것.
- 빈칸은 중간(20일)에 등록된 간호사라서 생긴 것.
- 보기 편한 건 월간 뷰. 수기 작성은 모바일 웹에서도 바로 할 수 있어야 함.

## 5. 일반 간호사 페이지

- "내 신청" 화면에 "받은 신청이 없어요"라는 문구가 나옴. 수간호사 화면을 그대로 가져다 써서 생긴 문제.
- "내 통계"도 수간호사용 문구("간호사별 근무 횟수…")가 그대로 들어가 있음. 일반 간호사 기준으로 다시 작성할 것.
- 지적받은 부분을 우기지 말고 수정할 것.

## 6. 간호사 관리

- 수정 버튼이 텍스트로만 되어 있고 API 명세에도 없음. 수정 기능과 API를 추가할 것.
- (회의 후) 기능 논의 때 수정 기능이 빠졌는데 프론트만 먼저 만들어서 생긴 갈등. **명세에 없는 기능은 먼저 합의한 뒤 만들기.**

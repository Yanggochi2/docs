# PM 미팅 정리 (2026-10-12)

> PM 3차 미팅 정리입니다. 노션 회의록(PM 미팅 > 3차-10월12일월요일)을 옮겼어요.
>
> 같은 날(10-12) 진행한 클라이언트 3차 미팅을 총평·피드백·도메인 Q&A 중심으로 요약한 페이지예요. 미팅 원문 정리는 [클라이언트 미팅 (10-12)](클라이언트_미팅_2026-10-12.md)에 있어요.

## 총평

도메인 질의응답은 매우 좋았어요 ("이런 미팅이 처음부터 있어야 한다"). 다만 결과물이 부족했어요. 미팅에는 **실제로 동작하는 결과물**을 가져오고, 그 전에 팀 내부 회의로 미리 정리해 둘 것.

## 1. 현재 상태

- 디자인과 랜딩 페이지만 있어요. 기능은 개발했지만 프론트와 백엔드가 **연동이 안 된 상태**예요.
- 사용자 추가와 로그인의 관계는 백엔드에서 짜 놨지만 화면에는 아직 반영되지 않았어요.

## 2. 피드백

- **사용자 추가**: 로그인한 사람이 곧 수간호사예요. 근무표 작성은 수간호사 고유 업무이므로 역할/권한 구분(프리셉터 등)은 의미가 없어요. 2~3주째 같은 얘기를 하고 있으니 꼭 반영할 것.
- **월별 근무표**: 목 데이터라도 **근무별 정원을 현실적으로** 넣어야 자동 생성이 잘 되는지 검증할 수 있어요. 공휴일(빨간 날)도 표시할 것.
- **자동 생성 규칙**: 현재 5개. "나이트 연속 후 무조건 휴무" 규칙을 추가할 것. 규칙은 병원마다 다를 수 있으므로 업체에 요청하는 방식이 아니라 **사용자가 화면에서 직접 추가**할 수 있게 고민할 것.
- **플랫폼**: 수간호사는 웹(PC)에서 근무표를 작성해요. 일반 간호사는 모바일로 자기 근무표를 조회하고 오프를 신청하는 정도예요.

## 3. 도메인 Q&A (규칙 설계용)

| 항목 | 답변 |
|---|---|
| 나이트 후 휴무 | 필수 1일, 권장 2일 |
| 최대 연속 근무 | 대략 5일 |
| 주휴 | 월 4회만 맞추면 됨 (권장은 주 1회). 오프 수 = 해당 월 공휴일 + 1 개념 |
| 임산부 | 권장: 평일 데이만. 초기·후기에 근무 단축 (임신 기간 전체 단축하는 병원도 있음) |
| 나이트 전담 | 일부 병동에 제도가 있음. 지원하면 나이트만 근무 |
| 희망 오프 개수 | 시스템으로 막지 않음. 사전 구두 협의로 해결하는 영역 |
| 오프 신청 마감 | 정해진 기준 없음. 근무를 짜는 시점 기준이며, **다음 달 시작 10일 전**으로 잡기로 함 |
| 숙련도 | 수간호사의 주관적 판단. 대략 **총 경력 30% + 해당 병동 경력 70%** |
| 프리셉터 | 보통 4~5년 차가 맡음 |
| 복귀 간호사 | 1인분으로 배치. 신규로 자동 등록하지 말고 히스토리를 보고 그룹을 지정할 수 있게 |
| 간호사 등록 정보 | 비고/히스토리 자유 기재란 추가 (이전에 주로 있던 병동 등이 중요) |
| 차지 간호사 | 근무표 데이 칸에 명시. 수간호사는 실무를 하지 않음 |

## 4. 다음 주까지

- 프론트·백엔드 연동 후, 동작하는 상태로 시연

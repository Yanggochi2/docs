# 클라이언트 미팅 정리 (2026-10-06)

> 클라이언트 2차 미팅 내용을 정리한 문서입니다. 노션 회의록(클라이언트 미팅 > 2차-10월6일화요일)을 옮겼어요.

## 디자인 전반

- 전반적인 디자인이 마음에 들지 않으셨어요. **수정하고 가독성을 높이는 게 필수**예요.
- 주간으로 나오던 엑셀형 근무표도 마음에 안 드셨어요.
	- **기본은 월별**로 보여주고, 확인할 때는 **주간으로도** 볼 수 있게 해요.

## 간호사 등록

- 사용자 연령대가 50대 정도라서 간호사 등록 페이지에 **간단한 설명**이 있으면 좋겠다고 하셨어요.
- **총 경력** 항목이 왜 있는지 모르겠다고 하셨어요.
	- 다른 병동으로 가면 하던 업무가 아니라서 경력이 필요 없다고 하셨어요.
- **입사일**을 왜 입력해야 하는지 모르겠다고 하셨어요.
	- 입사일은 빼고, **소속 시작일**(해당 병원에서 근무를 시작한 날)을 위쪽에 배치해 달라고 하셨어요.
- **숙련도 5단계**가 이해하기 어렵다고 하셨어요. 아래처럼 **3단계**가 좋겠다고 하셨어요.
	1. 혼자서 근무 불가능
	2. 혼자서 근무 가능
	3. 1단계 간호사를 데리고 근무 가능

## 반영이 필요한 것

- [ ] 디자인 가독성 개선
- [ ] 근무표 기본 보기를 월별로, 주간 보기는 보조로
- [ ] 간호사 등록 화면에 설명 추가
- [ ] 총 경력·입사일 항목 제거, 소속 시작일을 상단으로
- [ ] 숙련도를 5단계에서 3단계로 변경 (기능명세서·API명세서·백엔드 반영 필요)

# 클라이언트 미팅 정리 (2026-10-26)

> 클라이언트 5차 미팅 정리입니다. 노션 회의록(클라이언트 미팅 > 5차-10월26일월요일)을 옮겼어요.
>
> **기능 범위가 크게 바뀐 미팅이에요.** 일반 간호사의 오프 신청과 로그인을 빼고, 공유 링크로 근무표를 보는 방식으로 바뀌었어요.

## 1. 근무표 화면 및 정렬

- **기본 화면**: 근무표 진입 시 **월간**으로 출력
- **정렬 옵션 단순화**: 직급순·경력순·숙련도순처럼 여러 개 둘 필요 없음 → **숙련도순 / 이름순 2개만**
	- **숙련도순 (기본값)**: 수간호사 → 차지 간호사 **상단 고정**, 이후 일반 간호사는 **경력 내림차순**
	- **이름순**: 직급 구분 없이 섞어도 됨
- 현재는 초기 정렬이 이름순으로 되어 있음 → 수정 필요

## 2. 서비스 이해도 지적

- 팀 전반의 **도메인(간호 현장) 이해도가 낮음**. 개발 실력이 아니라 무엇을 만드는지에 대한 이해 문제예요.
- **프리셉터는 높은 직급이 아님**: 신규 간호사가 들어오면 가르치는 선임 역할이며, 주로 5~6년 차가 맡아요 (23년 차가 맡지 않음).
- 경력과 직급은 별개예요: 25년 차 일반 간호사, 23년 차 차지 간호사도 있을 수 있어요 → 그래서 직급 고정 후 경력 정렬.
- 모르는 부분은 클라이언트에게 적극적으로 질문할 것.

## 3. 목데이터 기준

- 데이터는 경력·직급이 **다양하게 섞이도록** 구성
- 한 병동 세팅 기준: **수간호사 1, 차지 간호사 2, 일반 간호사 25, 프리셉터는 일반 간호사 중 적절히 지정** (총 28명)

## 4. 자동 생성 알고리즘 문제

- **차지 간호사**: 주 5일 근무 + 주말 휴무여야 하는데, 주중에 오프가 들어가 있음
- **이브·나이트가 너무 많음**: 이브와 나이트를 한 세트로 묶는 방식은 말이 안 됨
- **특정 인원에게 근무 편중**: 노은서, 권태호, 김수관 등 (이름은 녹음 기준)
- 지난 회의의 "하루 일하고 하루 쉬기가 이상하다"는 피드백 후 "이틀 일하고 하루 쉬기"로만 바뀜 → 근본적인 해결이 안 됨
- **월 오프 12~13개는 근거가 없음** → **주말 + 공휴일 + 1일**만 쉬는 것이 기준 (첫 미팅 때 전달한 내용)
- 다시 짜기(재생성) 기능이 제대로 안 되면 빼도 됨

> 팀 측 설명: 공휴일·주말 오프를 계산하고, 교육일·학회·연차는 고정으로 처리함. 나이트를 먼저 배치한 뒤 월 오프를 간호사별로 균등하게(12~13개) 분배함. 규칙 확인 후 AI와 함께 작성함.
>
> → 클라이언트: 알고리즘 전면 재검토 필요

## 5. 클라이언트 요청사항: 기능 범위 변경

- **일반 간호사 오프 신청 기능 삭제**
	- 오프 신청은 **병동에 둔 종이 달력**에 이름을 적는 방식으로 진행
	- 이유: 달력에서는 다른 사람의 신청 현황이 보여, 자리가 차면 각자 다른 날로 조정함. 온라인으로 받으면 시스템이나 수간호사가 일일이 조율해야 함
- **일반 간호사 로그인 제거** → 일반 간호사는 공유 링크로 **조회만** 가능
	- 수간호사는 지금처럼 **로그인해서** 병동과 근무표를 관리함 (11-02 팀 확인)
- **공개하기 버튼 → 공유 링크** 배포로 누구나 근무표 확인

## 6. 수간호사 기능

- **사용자(간호사) 생성 기능 추가**
	- 등록 창은 "간호사 정보 수정" 화면과 같은 폼으로 만들어 수정에도 재사용
- **입사일 → 입사 연도만** 입력, 소속 시작일은 그대로 유지
- 수간호사가 인원을 등록하고 근무표를 직접 생성할 수 있는 흐름 완성

## 7. 기타

- 개발 진척도가 늦다는 지적
- 세부 내용은 노션에 정리되어 있으니 참고하고, 기능 개발 계속 진행

## Action Items

1. 기본 화면 월간 뷰, 정렬 옵션 2개(숙련도순 기본, 이름순)로 변경
2. 목데이터 재구성 (28명, 경력·직급 다양화)
3. 근무표 알고리즘 재설계 (차지 주5일, 이브·나이트 분배, 오프 = 주말 + 공휴일 + 1, 근무 편중 해소)
4. 일반 간호사 로그인·오프 신청 기능 제거, 공유 링크 조회 방식 적용
5. 수간호사 간호사 등록 기능 추가 (수정 폼 재사용, 입사 연도만 입력)
6. 간호 근무 도메인 이해도 높이기 (프리셉터, 차지 역할 등)

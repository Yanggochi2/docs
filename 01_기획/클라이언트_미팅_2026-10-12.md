# 클라이언트 미팅 정리 (2026-10-12)

> 클라이언트 3차 미팅(멘토링) 내용을 정리한 문서입니다. 노션 회의록(클라이언트 미팅 > 3차-10월12일월요일)을 옮겼어요.

## 진행 상황 시연

랜딩 페이지, 사용자 추가 화면, 월별 근무표, 자동 생성 화면을 보여줬어요. 자동 생성에는 규칙 5개가 들어가 있어요.

다만 백엔드와 프론트가 아직 연동되지 않아 실제 동작은 시연하지 못했어요. 데이터도 목 데이터뿐이었어요.

## 멘토 피드백

- 미팅 전에 팀 내부 회의로 결과물을 정리하고, **실제로 동작하는 기능**을 가지고 시연해야 해요.
- 사용자 추가 화면에 지난번 피드백이 반영되지 않았어요. 2~3주째 같은 얘기를 듣고 있어요.
	- 수간호사 계정으로 로그인한 상태라서 간호사 유형을 선택하는 건 의미가 없어요.
	- 역할과 권한을 나눠둔 것도 의미가 없어요.
	- **사용자 추가와 로그인의 관계**를 정리해야 해요.
- 목 데이터라도 근무별 인원 수 같은 **현실적인 값**을 넣어야 자동 편성이 제대로 되는지 검증할 수 있어요.
- 월별 근무표에 **공휴일(빨간 날) 표시**가 필요해요.
- 규칙은 병원마다 다르므로, **사용자가 화면에서 규칙을 직접 추가**할 수 있는 방식을 고민해야 해요. 예: "나이트 3일 후 오프"

## 도메인 Q&A

| 주제 | 답변 |
|---|---|
| 임산부 | 권장 규칙으로 **평일 데이 근무만** 배정해요. 임신 초기·후기에 근무를 단축하고, 기간 전체를 단축하는 병원도 있어요. |
| 나이트 전담 (나이트 킵) | 일부 병동에만 있는 제도이고, 지원자에 한해요. |
| 나이트 후 휴무 | **필수 1일, 권장 2일**이에요. |
| 최대 연속 근무 | 약 **5일**이에요. |
| 주휴 | **월 4회**만 맞추면 되고, 여기에 해당 월 **공휴일 수 + 1**을 더해요. |
| 희망 오프 | 시스템으로 개수를 제한하기보다 **사전 구두 협의**로 처리해요. 신청 마감은 다음 달 근무 작성일 **약 10일 전**이에요. |
| 간호사 등록 | 경력 외에 주로 근무했던 병동 같은 히스토리를 자유롭게 적을 수 있는 **비고란**이 필요해요. |
| 복귀 간호사 | 1인분 간호사로 배치해요. 히스토리를 보고 숙련 그룹이나 프리셉터로 지정할 수 있어야 해요. |
| 숙련도 | 수간호사가 **주관적으로 판단**해요. 대략 총경력 30% + 해당 병동 경력 70% 비중이에요. |
| 프리셉터 | 보통 4~5년차가 맡아요. |
| 사용 형태 | 수간호사는 **PC 웹**으로 근무표를 작성하고, 일반 간호사는 **모바일**로 근무표 확인과 오프 신청을 해요. |
| 차지 간호사 | 고정 역할이 아니라 **해당 날짜 근무에 명시**해요. |

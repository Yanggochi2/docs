# 클라이언트 미팅 정리 (2026-11-02)

> 클라이언트 6차 미팅 정리입니다. 노션 회의록(클라이언트 미팅 > 6차-11월2일월요일)을 옮겼어요.
>
> **핵심 방향: 근무표 작성에만 집중해요.** 부가 기능은 빼도 되고, 근무표 전체를 한 화면에서 볼 수 있게 정리해요.

## 1. 핵심 방향

- 근무표 작성에만 집중한다. 부가 기능은 빼도 된다.
- 근무표 전체를 한 화면에서 볼 수 있게 하고, 잡다한 요소는 정리한다.

## 2. 버그

- 새 병동이 생성되지 않음
- 자동생성 후 첫 화면이 주간 보기로 뜸 (기본 화면을 어떻게 할지 확인 필요)

## 3. 기능 추가 / 수정

**간호사 관리**

- 간호사 추가/삭제 기능
- 간호사 정보 수정: 수정 창 자체가 없어서 새로 만들어야 함
- 엑셀 일괄 등록: 샘플 양식을 다운로드해서 작성한 뒤 업로드하는 방식

**근무표**

- 희망 오프 입력 받기
- 잔여 오프 수 표시: 이름 옆에 두거나 고정 영역에 배치
- 근무표 공유 기능

## 4. 근무 규칙 / 알고리즘

- 야간 연속 근무를 **2일에서 3일**로 변경
- **7·5·5 기준**을 넘으면 오프를 부여해서 지키도록 함
	- 실제로는 8일, 10일 연속 근무도 있을 수 있지만, 자동생성이라면 기준 초과 여부는 인지하고 있어야 함

## 5. UI

- 근무 칸에 배경색을 넣고 글자를 흰색으로 바꾸는 방식 시도

## 6. 성능

- 클라이언트 피드백: 생성 속도가 느려서 알고리즘으로 돌아가는 것 같지 않다고 함
- 할 일: 느린 원인 분석 (담당: 민서)

## 확인 필요

- "7·5·5"가 각각 무엇을 뜻하는지 (근무 유형별 연속 근무 상한인지, 다른 기준인지) 클라이언트에게 다시 확인해야 해요.
	- 참고: [근무표 작성 유의사항 (10-27)](../02_명세서/근무표_작성_유의사항.md)에는 기본 인원 D7·E5·N5로 적혀 있어요.

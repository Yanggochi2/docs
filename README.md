# 간호사 근무표(듀티) 자동 생성 서비스

수간호사가 매달 손으로 짜는 3교대 근무표를 **규칙 기반으로 자동 편성**하고, 만들어진 근무표의 **문제(인력 부족·근무 편중·금기 패턴)를 찾아주는** 웹 서비스입니다.

## 한눈에 보기

| 항목 | 내용 |
|---|---|
| 주 사용자 | 수간호사 (50대 이상 → 큰 화면·큰 글씨, 엑셀과 비슷한 UI) |
| 부 사용자 | 일반 간호사 (확정 근무표 조회, 연차·희망 오프 신청) |
| 수익 모델 | 무료 제공 + 광고 |
| 기간 | 약 7주 |
| 메인 컬러 | 버건디 + 화이트 |
| 근무 유형 | `D` Day / `E` Evening / `N` Night / `O` Off (+ `AL` 연차) |
| 기술 스택 | React / Spring / PostgreSQL (세부 스택은 미정) |

## 팀

| 이름 | 역할 |
|---|---|
| 김효주 | 인프라 구축, 프론트 |
| 이석찬 | 프론트 |
| 김민서 | 백, QA |
| 최수혁 | 백, 발표 |

## 핵심 기능

- **간호사 관리**: 등록·수정·퇴사, 역할(차지/프리셉터/신입/일반), 숙련도, 소속 기간
- **근무 규칙 관리**: 하드/소프트 제약, 공휴일, 월 OFF 목표, 규칙 프리셋
- **근무표 자동 생성**: 제약 최적화 솔버로 편성, 진행률 표시, 해 없음 시 원인·완화안 제시
- **근무표 편집·검증**: 엑셀형 매트릭스 그리드, 커버리지 집계, 규칙 위반 표시, 확정/확정 취소
- **신청**: 연차·희망 오프 신청과 승인
- **보안**: 병동 단위 접근 통제, 역할별 응답 필드 차등, 감사 로그

# 간호사 근무표 서비스 비즈니스 로직

> 클라이언트 3차 미팅(10-12) 도메인 Q&A를 반영해 정리한 현재 기준 로직입니다 (2026-10-19). 노션(명세서 > 비즈니스로직(10월19일 반영))을 옮겼어요.
> 기능명세서 v1.0·[처리 로직 v1.0](처리로직_v1.0.md)과 다른 부분은 이 문서가 우선합니다.

## 1. 사용자와 권한

- **권한은 2단계만 둡니다.**
	- **수간호사:** 병동 관리자. PC 웹에서 간호사 등록, 근무표 작성·수정, 규칙 관리를 합니다.
	- **일반 간호사:** 모바일에서 본인 근무표 확인과 희망 오프 신청만 합니다.
- 역할과 권한을 따로 나누지 않습니다. 프리셉터, 숙련 그룹, 차지는 권한이 아니라 **간호사 속성이나 근무 단위 표시**로 처리합니다.
- 수간호사가 간호사를 등록하면 그 간호사의 로그인 계정이 생깁니다. 흐름안(10-20 확정 예정): 수간호사 가입 → 병동 생성 → 간호사 등록 → 계정 발급 → 간호사 첫 로그인 시 비밀번호 설정
- 1명의 수간호사가 1개 병동을 관리합니다.

## 2. 간호사 프로필

| 항목 | 설명 |
|---|---|
| 이름, 소속, 총경력 | 기본 정보 |
| 병동 경력 | 현재 병동에서의 경력 |
| 히스토리(비고) | 자유 서술. 이전 근무 병동, 전입·복귀 이력 등 |
| 숙련 그룹 | 수간호사가 지정. 참고 기준은 총경력 30%, 병동 경력 70% |
| 프리셉터 여부 | 보통 4~5년차. 프리셉티와 매칭 |
| 근무 제한 상태 | 임신, 출산 후 복귀, 나이트 킵 등 |

- 복귀 간호사는 신규로 자동 분류하지 않습니다. 1인분 간호사로 배치하고, 수간호사가 히스토리를 보고 숙련 그룹이나 프리셉터로 지정할 수 있게 합니다.
- 숙련도는 자동으로 산출하지 않습니다. 위 비율은 추천값으로만 보여주고, 최종 지정은 수간호사가 합니다.

## 3. 근무표 생성 흐름

1. 수간호사가 대상 월을 선택합니다.
2. 희망 오프 신청을 마감합니다(근무표 작성일 약 10일 전).
3. 자동 생성을 실행합니다. 규칙과 희망 오프를 반영해 초안을 만듭니다.
4. 수간호사가 직접 수정합니다. 규칙 위반이 생기면 경고를 띄웁니다.
5. 근무표를 확정하고 간호사들에게 공개합니다.

**화면 표시**

- 날짜별·근무별(D/E/N) 인원 수
- 공휴일(빨간 날)
- 그날의 차지 간호사

## 4. 규칙 엔진

규칙은 **필수**(위반하면 생성 불가 또는 경고)와 **권장**(가능하면 지킴)으로 나눕니다. 병원마다 규칙이 다르므로 **수간호사가 화면에서 직접 추가하고 수정**할 수 있어야 합니다.

| 규칙 | 필수 | 권장 |
|---|---|---|
| 나이트 후 휴무 | 1일 | 2일 |
| 최대 연속 근무 | 5일 | – |
| 월 휴무 수 | 주휴 4회 + 해당 월 공휴일 수 + 1 | – |
| 근무별 최소 인원 | 병동 설정값 | – |
| 임신 간호사 | – | 평일 데이만, 초기·후기 근무 단축 |
| 나이트 킵 | 지원자만 나이트 전담 | – |

- 월 휴무 수의 "+1"은 1차 미팅 메모 기준 **생리휴가**입니다 (근로기준법 §73). 모든 간호사에게 주는지는 미확인이에요 ([근무 규칙 Q7](근무규칙.md#q7-월-off-개수-계산-)).
- 나이트 후 휴무의 적용 조건(나이트 몇 회 후인지)은 10-20에 확인합니다.
- 규칙을 추가하는 방식은 "조건 + 결과" 템플릿을 제안합니다. 예: `[나이트] [3일] 연속 후 → [오프] [1일] 이상`
	- 규칙별로 필수/권장을 지정합니다.
	- DB 저장 항목: 규칙 유형, 파라미터, 필수/권장, 병동, 사용 여부
- 법에서 정한 공통 규칙은 기본값으로 넣어두고, 병원별 규칙은 사용자가 추가하게 합니다.

## 5. 희망 오프

- 간호사가 모바일 달력에서 해당 월에 신청합니다.
- 신청 개수는 시스템에서 제한하지 않습니다. 개수 조율은 사전 구두 협의로 처리합니다.
- 승인과 반려 절차는 없습니다. 자동 생성 시 입력값으로만 반영하고, 반영하지 못하면 수간호사에게 표시합니다.

## 6. 차지 간호사

- 고정 역할이 아니라 **날짜·근무 단위로 지정**합니다.
- 근무표의 해당 칸에 차지 표시를 합니다.

## 클라이언트에게 확인할 항목

- 같은 날 희망 오프가 몰릴 때 우선순위 기준
- 실제 근무표 예시 공유 가능 여부
- 병원 사내 메신저 유무(알림 채널을 정하는 데 필요)
- 오프 신청 마감 10일 전이 확정인지
- 월 휴무 계산식("주휴 4회 + 공휴일 수 + 1")의 정확한 의미
- 근무별 최소 인원의 실제 값

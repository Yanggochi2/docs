# 간호사 근무 규칙 (클라이언트 확인용)

클라이언트 미팅 때 질문하면서 **우리가 이해한 근무 규칙이 맞는지 교차검증**하려고 만든 문서입니다. 미팅 내용, 기능명세서, 법·가이드라인 조사를 비교해서 확인이 필요한 것만 질문으로 뽑았습니다.

> 미팅 중에 각 질문의 **답변** 칸을 채우고, 끝나면 확인 상태를 ✅로 바꿔 주세요.

## 한눈에 보기

| 규칙 | 지금 기준 | 근거 | 확인 |
|---|---|---|---|
| 근무 유형 | D / E / N / Off (+ 연차) | 클라이언트 | ✅ |
| 임산부 나이트 금지 | 하드 규칙 | 클라이언트 + 근로기준법 §70 | ✅ |
| 임산부 휴일 근무 금지 | **명세서에 없음** | 근로기준법 §70 | ❓ Q1 |
| 산후 1년 미만 나이트 금지 | **명세서에 없음** | 근로기준법 §70 | ❓ Q1 |
| 나이트 후 휴식 | 클라이언트는 "2회 후 1일", 가이드라인은 "2일 연속 후 48시간" | 클라이언트 / 복지부 가이드라인 | ❓ Q2 |
| 연속 나이트 상한 | 값 미정 (가이드라인은 3일) | 복지부 가이드라인 | ❓ Q3 |
| 금기 패턴 (나데·이데·나이) | **명세서에 없음** | 현장 관행 | ❓ Q4 |
| 연속 근무일 상한 | 없음 (현장은 5일) | 현장 관행 | ❓ Q5 |
| 주휴일 (7일 중 1일 OFF) | 미정 | 근로기준법 §55 | ❓ Q6 |
| 월 OFF 목표 | 공휴일 수 + 1 (생리휴가) | 클라이언트 | ❓ Q7 |
| 차지 간호사 | D만 근무 | 클라이언트 | ❓ Q8 |
| 신입 나이트 단독 금지 | 하드 규칙 | 클라이언트 | ❓ Q9 |
| 숙련도 | 3단계로 변경 예정 | 클라이언트 (10-06) | ❓ Q9 |
| 필요 인원 | 날짜·듀티별 최소 인원 | 명세서 | ❓ Q10 |
| 희망 오프 | 승인 시 소프트 반영, 월 한도 미정 | 클라이언트 + 명세서 | ❓ Q11 |
| 근무표 단위 | 월 단위 | 클라이언트 (10-06) | ✅ |

## 질문 목록

### Q1. 임산부·산후 간호사 근무 제한

- **지금 이해**: 임신한 간호사는 나이트에서만 빼요.
- **근거**: 근로기준법 §70②는 임산부에게 **22시~06시 근무와 휴일 근무**를 모두 금지해요. 법에서 말하는 임산부에는 **산후 1년 미만**도 들어가요. 본인이 동의하거나 청구하고 노동부 인가를 받으면 예외예요.
- **질문**
  - 병원에서 임신한 간호사에게 주말·공휴일 근무도 안 시키나요?
  - 출산 후 복귀한 간호사(1년 미만)도 나이트에서 빼나요?
  - 본인이 원해서 나이트를 하는 경우가 실제로 있나요?
- **답변**:

### Q2. 나이트 후 휴식

- **지금 이해**: "나이트 2회 후에는 반드시 1일 휴식" (1차 미팅)
- **근거**: 복지부 「간호인력 야간근무 가이드라인」(2019)은 **나이트를 2일 이상 연속하면 48시간 이상 휴식**을 보장하라고 해요. 근무표로 치면 `N N O O`예요.
- **질문**
  - 나이트 2번 뒤 쉬는 날이 1일인가요, 2일인가요?
  - 나이트를 1번만 한 다음날은 바로 근무해도 되나요?
- **답변**:

### Q3. 연속 나이트 최대 일수

- **지금 이해**: 상한이 있다는 것만 알고 값은 몰라요.
- **근거**: 같은 가이드라인에 **연속 나이트 3일 이하**로 나와 있어요.
- **질문**: 나이트를 최대 며칠 연속으로 넣나요? 3일이 맞나요?
- **답변**:

### Q4. 금지 근무 패턴

- **지금 이해**: 1차 미팅에서 "나이트 → 데이 직행 금지 등"이라고 들었고, 전체 목록은 받지 못했어요.
- **근거**: 법이나 가이드라인에는 없고 현장 관행이에요. 조사로 찾은 패턴은 아래와 같아요.

  | 패턴 | 속칭 | 휴식 시간 |
  |---|---|---|
  | N → D | 나데 | 0시간 (07시 퇴근, 07시 출근) |
  | E → D | 이데 | 8시간 (23시 퇴근, 07시 출근) |
  | N → E | 나이 | 8시간 (07시 퇴근, 15시 출근) |

- **질문**
  - 위 세 가지가 다 금지인가요? 아니면 피하기만 하면 되나요?
  - 이것 말고 피하는 패턴이 있나요? (예: `D O N`, 고립 근무일)
- **답변**:

### Q5. 연속 근무일 최대 일수

- **지금 이해**: "연속 근무와 휴식 규칙이 있다"는 것만 들었어요.
- **근거**: 법 근거는 없고, 현장에서는 보통 5일 이하로 잡아요.
- **질문**: 쉬는 날 없이 최대 며칠까지 연속 근무시키나요?
- **답변**:

### Q6. 주휴일

- **지금 이해**: 명세서에서 결정을 미뤄 뒀어요 (D-07).
- **근거**: 근로기준법 §55①은 **1주에 평균 1회 이상 유급휴일**을 보장하라고 해요.
- **질문**: 매주 최소 1일 OFF를 꼭 지키나요? 아니면 한 달 전체 OFF 개수만 맞추나요?
- **답변**:

### Q7. 월 OFF 개수 계산

- **지금 이해**: OFF = **그 달 빨간날 수 + 1** (Q/A 메모: "+1은 생리")
- **근거**: 생리휴가는 근로기준법 §73에 따라 여성이 청구하면 월 1일을 줘요. 법 기준은 무급이에요.
- **질문**
  - 주말 OFF는 따로 주고, 거기에 빨간날 수 + 1을 더하는 건가요?
  - +1은 모든 간호사에게 주나요? (남성 간호사, 신청하지 않은 사람)
  - 예시: 공휴일이 2일인 30일짜리 달이면 한 사람 OFF가 총 며칠인가요?
- **답변**:

### Q8. 차지 간호사

- **지금 이해**: Q/A 메모 "차지 데이만 고정" → 차지는 D만 근무해요.
- **근거**: 리서치에서는 모든 듀티(특히 N)에 책임자급 1명이 필요하다는 의견이 있었어요.
- **질문**
  - 차지는 데이 고정이 맞나요?
  - E·N에는 책임자 역할을 하는 사람이 따로 필요한가요? 필요하면 어떤 조건인가요? (숙련도 3단계 등)
- **답변**:

### Q9. 신입·숙련도 배치

- **지금 이해**: 신입은 나이트에 혼자 들어가면 안 돼요. 숙련도는 3단계로 바꿔요 (2차 미팅).
  1. 혼자서 근무 불가능
  2. 혼자서 근무 가능
  3. 1단계 간호사를 데리고 근무 가능
- **질문**
  - "1단계가 있는 듀티에는 3단계가 최소 1명 있어야 한다"로 이해하면 되나요?
  - 이 규칙은 나이트만인가요, 모든 듀티인가요?
  - 한 듀티에 1단계를 최대 몇 명까지 넣을 수 있나요?
  - 신입과 프리셉터를 같은 듀티에 꼭 묶어야 하나요?
- **답변**:

### Q10. 필요 인원

- **지금 이해**: 날짜·듀티별 최소 인원을 수간호사가 정해요. 평일·주말·공휴일을 나누는 안을 권장해요 (D-08).
- **질문**
  - 병동 하나에 간호사가 보통 몇 명인가요?
  - D / E / N 각각 최소 몇 명인가요? 주말·공휴일엔 다른가요?
  - 실제 근무표 예시를 받을 수 있을까요? (개인정보는 지우고)
- **답변**:

### Q11. 희망 오프·연차 신청

- **지금 이해**: 연차는 승인되면 무조건 반영하고, 희망 오프는 가능하면 반영해요.
- **질문**
  - 한 사람이 한 달에 희망 오프를 몇 개까지 신청할 수 있나요?
  - 같은 날 신청이 몰리면 누구를 우선하나요? (연차, 경력, 지난달 미반영자 등)
  - 신청 마감은 보통 언제인가요?
- **답변**:

## 이미 확정된 것

미팅에서 다시 물어볼 필요가 없는 내용입니다.

- 3교대 **D / E / N / Off**, 연차는 `AL`로 표시
- 승인된 연차 날짜에는 근무 배정 금지
- 소속 기간 밖 날짜에는 배정 금지
- 휴직(`ON_LEAVE`)·퇴사 간호사는 배정에서 제외
- 숙련도는 수간호사만 볼 수 있음
- 근무표 기본 보기는 월별, 보조로 주간 보기

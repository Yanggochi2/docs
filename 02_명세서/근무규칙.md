## 1. 듀티 코드

| 코드 | 명칭 | 시간대 (기본값) | 규칙 | 출처 |
|---|---|---|---|---|
| `D` | Day | 07:00 ~ 15:00 | 직접 입력 가능 | 🟢 📘 |
| `E` | Evening | 15:00 ~ 23:00 | 직접 입력 가능 | 🟢 📘 |
| `N` | Night | 23:00 ~ 익일 07:00 | 직접 입력 가능 | 🟢 📘 |
| `O` | Off | — | 직접 입력 가능 | 🟢 📘 |
| `AL` | 연차 | — | 승인된 연차만 자동 입력. 직접 입력 불가 | 📘 |
| `ED` | 교육 | — | 1차 출시에서 제외 권장 (D-02) | 📘 |
| `null` | 미배정 | — | `O`와 다름. 커버리지 인원에서 빠짐 | 📘 |

- 시간대는 병원마다 다르므로 하드코딩하지 않고 병동별 설정으로 둡니다. 🔍
- 근로기준법상 야간은 **22:00 ~ 06:00**이에요(⚖️ §56·§70). `N`(23~07시)은 이 구간과 겹치므로 법의 "야간근로"에 해당합니다.

## 2. 하드 규칙: 위반 시 근무표 확정 불가

| ID | 규칙 | 출처 | 검증 | 근거·비고 |
|---|---|---|---|---|
| H-01 | 1인 1일 1듀티 | 🔍 | — | 데이터 구조상 자동 보장 |
| H-02 | 소속 기간 밖 날짜에는 배정 금지 | 📘 | — | 셀 비활성화, 커버리지에서 제외 |
| H-03 | **임산부는 `N` 배정 금지** | 🟢 📘 ⚖️ | ✅ | §70② "사용자는 임산부와 18세 미만자를 오후 10시부터 오전 6시까지의 시간 및 휴일에 근로시키지 못한다." 임산부에는 **산후 1년 미만**도 포함돼요. 본인 동의·청구 + 고용노동부장관 인가가 있으면 예외(§70③) |
| H-04 | **임산부는 휴일 근무도 금지** | ⚖️ | ✅ | 같은 §70②. 클라이언트는 N 제외만 말했지만 법은 휴일 근무도 막아요. → [5장 #1](#5-출처-간-차이와-결정-필요-항목) |
| H-05 | 신입(`NEW`)은 `N`에 단독 배치 금지 | 🟢 📘 | — | 클라이언트 예시: "신입이 나이트에 혼자 들어가면 안 됨" |
| H-06 | 차지(`CHARGE`)는 `D`만 배정 | 🟢 📘 | — | Q/A 메모: "차지 데이만 고정" |
| H-07 | **연속 `N` 3일 이하** | 📘 🏛️ | ☑️ | 가이드라인: "연속 야간근무는 3일 이하로 제한" |
| H-08 | **`N` 2일 이상 연속 후 48시간 이상 휴식** | 🟢 🏛️ | ☑️ | 가이드라인: "야간근무를 2일 이상 연속한 경우 48시간 이상의 휴식 보장". 근무표에서는 **N 블록 직후 OFF 2일**과 같아요. 클라이언트가 말한 "나이트 2회 후 1일 휴식"보다 엄격합니다 |
| H-09 | **1주 평균 1회 이상 유급휴일** | ⚖️ | ✅ | §55① "사용자는 근로자에게 1주에 평균 1회 이상의 유급휴일을 보장하여야 한다." |
| H-10 | 날짜·듀티별 최소 인원(커버리지) 충족 | 📘 | — | 평일·주말·공휴일 구분 권장 (D-08) |
| H-11 | 승인된 연차(`AL`) 날짜에는 근무 배정 금지 | 📘 | — | 자동 생성 시 하드 제약 |

### 하드로 둘지 결정이 필요한 후보

| 규칙 | 검증 | 근거·비고 |
|---|---|---|
| 야간전담간호사 월 `N` 14일(또는 15일) 이하 | ☑️ | 가이드라인. 보도마다 "14일 이내"와 "월 15일 넘게 안 됨"으로 엇갈려요. 공고문 원문을 구하지 못했으니 **보수적으로 14일**을 기본값으로 권장. 우리 서비스에 야간전담 역할이 아직 없어서 당장은 해당 없음 |
| 야간전담 연속 기간 3개월 이하 | ☑️ | 가이드라인. 위와 같음 |
| `N` 다음날 `D` 금지 (나데) | ❓ | 현장 관행. 법·가이드라인에 명시 없음. 하지만 N이 다음날 07시에 끝나고 그날 D가 07시에 시작하므로 **휴식 0시간**. 사실상 불가능한 배정 |
| `E` 다음날 `D` 금지 (이데) | ❓ | 현장 관행. 23시 퇴근 후 07시 출근이라 휴식 8시간 |
| `N` 다음날 `E` 금지 (나이) | ❓ | 현장 관행. 07시 퇴근 후 15시 출근이라 휴식 8시간 |
| 연속 근무일 5일 이하 | ❓ | 현장 관행. 법 근거 없음 (§55의 주 1회 휴일과는 별개) |

## 4. 휴무·신청·인력 관련 규칙

### 4.1 월 OFF 목표

- **OFF 목표 = 해당 월 공휴일(빨간날) 수 + 1** 🟢 📘
  - Q/A 메모: "빨간날 + 1, +1은 생리"
  - `+1`은 생리휴가예요. 법상 **여성 근로자가 청구하면 월 1일**을 줘야 하고, 법정 기준은 **무급**이에요(⚖️ §73, ✅). 병원이 유급으로 운영하는지, 남성 간호사에게도 +1을 주는지는 병원 규정에 따라 달라요.
- **주휴일**: 법상 1주 평균 1회 유급휴일이 필수예요(H-09). 명세서는 주휴일 포함 여부를 별도 정책값으로 미뤄 뒀는데(D-07), 실제로는 주휴일 OFF가 **기본으로 깔리고** 그 위에 공휴일 수와 +1이 더해지는 구조가 맞아요. → [5장 #3](#5-출처-간-차이와-결정-필요-항목)
- 수간호사가 수동 조정할 수 있고, 조정 시 적용자와 사유를 기록해요. 📘
- 공휴일이 바뀌면 OFF 목표와 공휴일 근무 수를 바로 다시 계산해요. 📘

### 4.2 신청

| 신청 종류 | 승인 시 반영 | 출처 |
|---|---|---|
| 연차 (`ANNUAL_LEAVE`) | `AL` 자동 입력, **하드** 제약 | 🟢 📘 |
| 희망 오프 (`PREFERRED_OFF`) | **소프트** 제약 | 🟢 📘 |
| 희망 근무 (`PREFERRED_SHIFT`) | **소프트** 제약 | 📘 |

- 월 신청 한도는 설정값으로 둬요 (D-14).

### 4.3 간호사 상태와 역할

| 구분 | 값 | 근무 규칙 영향 | 출처 |
|---|---|---|---|
| 상태 | `ACTIVE` | 정상 배정 | 📘 |
|  | `PREGNANT` | `N`·휴일 근무 금지 (H-03, H-04) | 🟢 📘 ⚖️ |
|  | `ON_LEAVE` | 휴직. 배정 제외 | 🟢 📘 |
|  | `RETIRED` | 퇴사. 소속 종료일 이후 배정 불가 | 📘 |
| 배정 역할 | `CHARGE` | `D`만 (H-06) | 🟢 📘 |
|  | `PRECEPTOR` | 담당 신입과 같은 듀티 (S-01) | 📘 |
|  | `NEW` | `N` 단독 금지 (H-05) | 🟢 📘 |
|  | `GENERAL` | 제약 없음 | 📘 |

- 법상 "임산부"는 산후 1년 미만을 포함하므로 `PREGNANT` 상태는 **출산 후 1년까지 유지**하거나, 산후 상태를 따로 두는 게 맞아요.

### 4.4 숙련도

- 클라이언트 요청(10-06)으로 **5단계에서 3단계**로 바꿀 예정이에요. 명세서는 아직 1~5단계입니다. 🟢
  1. 혼자서 근무 불가능
  2. 혼자서 근무 가능
  3. 1단계 간호사를 데리고 근무 가능
- 숙련도는 **수간호사만** 볼 수 있어요. 🟢 📘

### 4.5 근무표 작성 단위 (참고)

- 복지부 「제2차 간호사 교대제 개선 시범사업 지침」(2025.7)은 예측 가능한 근무를 위해 일반병동 근무표를 **2개월 단위로 계획·운영**하라고 해요(✅ 원문 확인). 시범사업 참여 병원만 해당하므로 우리 서비스는 월 단위를 기본으로 하고, 2개월 계획은 확장 기능으로 봅니다.
- 같은 지침에는 연속 나이트나 휴식 일수 같은 근무 패턴 규칙이 **없어요**. 그 규칙들은 위의 2019년 야간근무 가이드라인에 있습니다.

## 5. 출처 간 차이와 결정 필요 항목

| # | 항목 | 차이 | 제안 |
|---|---|---|---|
| 1 | 임산부 휴일 근무 | 클라이언트·명세서는 N만 금지. 법은 **휴일 근무도 금지**(§70②) | `PREGNANT`에 휴일(주휴일·공휴일) 배정 금지를 하드로 추가. 본인 동의·인가 예외는 수간호사가 규칙을 끌 수 있게 |
| 2 | 나이트 후 휴식 | 클라이언트 "N 2회 후 1일 휴식" vs 가이드라인 "N 2일 이상 연속 후 48시간" | **가이드라인 기준(OFF 2일)을 기본값**으로 두고 일수를 파라미터로 노출. 클라이언트에게 가이드라인 기준이라고 알리기 |
| 3 | 주휴일 | 명세서는 OFF 목표에 포함할지 미정(D-07). 법은 필수(§55①) | "7일 중 1일 이상 OFF"를 하드 규칙으로 두고, OFF 목표 계산에 주휴일을 기본 포함 |
| 4 | 연속 N 상한 | 명세서는 값 없음 | 가이드라인대로 **3일** |
| 5 | 금기 패턴 (나데·이데·나이) | 공식 근거 없음, 현장 관행 | 기본은 하드(N→D, E→D)로 두되 병동별로 끌 수 있게 |
| 6 | 차지 배치 | 클라이언트·명세서는 "차지는 D 고정". 리서치는 "모든 듀티에 차지 1명 이상" | 클라이언트 기준 유지 |
| 7 | 숙련도와 신입 규칙 | 숙련도 3단계와 `NEW` 역할이 겹침 | "숙련도 1은 단독 근무 불가, 같은 듀티에 숙련도 3이 1명 이상"으로 일반화 검토 |
| 8 | 하드 규칙 충돌 시 | 해가 없을 때 무엇부터 완화할지 미정 (D-13) | **법 규칙(H-03, H-04, H-09)은 완화 불가**. 가이드라인·관행 규칙만 완화 후보로 제시 (GEN-04) |

# 간호사 근무 규칙 (클라이언트 확인용)

클라이언트 미팅 때 질문하면서 **우리가 이해한 근무 규칙이 맞는지 교차검증**하려고 만든 문서입니다. 미팅 내용, 기능명세서, 법·가이드라인 조사를 비교해서 확인이 필요한 것만 질문으로 뽑았습니다.

> 미팅 중에 각 질문의 **답변** 칸을 채우고, 끝나면 확인 상태를 바꿔 주세요.
> **최종 반영**: [클라이언트 3차 미팅 (2026-10-12)](../01_기획/클라이언트_미팅_2026-10-12.md)

| 표시 | 의미 |
|---|---|
| ✅ | 클라이언트 확인 완료 |
| 🟡 | 일부만 확인. 남은 질문 있음 |
| ❓ | 아직 확인 못 함 |

| 규칙 직접 추가 | 병원마다 규칙이 달라서 **사용자가 화면에서 추가** | 클라이언트 (10-12) | ✅ Q12 |
| 근무표 단위 | 월 단위 | 클라이언트 (10-06) | ✅ |

## 질문 목록

### Q1. 임산부·산후 간호사 근무 제한 🟡

- **지금 이해**: 임신한 간호사는 나이트에서만 빼요.
- **근거**: 근로기준법 §70②는 임산부에게 **22시~06시 근무와 휴일 근무**를 모두 금지해요. 법에서 말하는 임산부에는 **산후 1년 미만**도 들어가요. 본인이 동의하거나 청구하고 노동부 인가를 받으면 예외예요.
- **질문**
  - 병원에서 임신한 간호사에게 주말·공휴일 근무도 안 시키나요?
  - 출산 후 복귀한 간호사(1년 미만)도 나이트에서 빼나요?
  - 본인이 원해서 나이트를 하는 경우가 실제로 있나요?
- **답변** (10-12)
  - 권장 규칙으로 **평일 데이 근무만** 배정해요. 나이트·이브닝·주말·공휴일이 모두 빠지므로 법 기준보다 엄격해요.
  - 임신 **초기·후기**에 근무를 단축해요. 임신 기간 전체를 단축하는 병원도 있어요.
- **남은 질문**
  - 산후 1년 미만 간호사에게도 같은 규칙을 적용하나요?
  - "권장"이라고 했는데, 수간호사가 예외로 이브닝·주말을 넣을 수 있게 해야 하나요?
  - 근무 단축은 근무표에 어떻게 표시하나요? (단축 근무 코드가 따로 있는지)
- **반영 방향**: 임산부 = 평일 D만. 법 기준(나이트·휴일 금지)은 끌 수 없는 하드 규칙, 이브닝 금지는 권장(소프트) 규칙으로 나눠요.

### Q2. 나이트 후 휴식 🟡

- **지금 이해**: "나이트 2회 후에는 반드시 1일 휴식" (1차 미팅)
- **근거**: 복지부 「간호인력 야간근무 가이드라인」(2019)은 **나이트를 2일 이상 연속하면 48시간 이상 휴식**을 보장하라고 해요. 근무표로 치면 `N N O O`예요.
- **질문**
  - 나이트 2번 뒤 쉬는 날이 1일인가요, 2일인가요?
  - 나이트를 1번만 한 다음날은 바로 근무해도 되나요?
- **답변** (10-12): 나이트 후 휴무는 **필수 1일, 권장 2일**이에요.
- **남은 질문**: 나이트를 1번만 한 경우에도 다음날 OFF가 필수인가요?
- **반영 방향**: 나이트 블록 직후 OFF 1일은 하드, 2일은 소프트(가이드라인 48시간과 같음).

### Q3. 연속 나이트 최대 일수 ❓

- **지금 이해**: 상한이 있다는 것만 알고 값은 몰라요.
- **근거**: 같은 가이드라인에 **연속 나이트 3일 이하**로 나와 있어요.
- **질문**: 나이트를 최대 며칠 연속으로 넣나요? 3일이 맞나요?
- **답변**: (3차 미팅에서는 안 다뤘어요.) 멘토 예시 "나이트 3일 후 오프"로 보면 3일일 가능성이 높아요.

### Q4. 금지 근무 패턴 ❓

- **지금 이해**: 1차 미팅에서 "나이트 → 데이 직행 금지 등"이라고 들었고, 전체 목록은 받지 못했어요.
- **근거**: 법이나 가이드라인에는 없고 현장 관행이에요. 조사로 찾은 패턴은 아래와 같아요.

  | 패턴 | 속칭 | 휴식 시간 |
  |---|---|---|
  | N → D | 나데 | 0시간 (07시 퇴근, 07시 출근) |
  | E → D | 이데 | 8시간 (23시 퇴근, 07시 출근) |
  | N → E | 나이 | 8시간 (07시 퇴근, 15시 출근) |

- **질문**
  - 위 세 가지가 다 금지인가요? 아니면 피하기만 하면 되나요?
  - 이것 말고 피하는 패턴이 있나요? (예: `D O N`, 고립 근무일)
- **답변**: (3차 미팅에서는 안 다뤘어요.) "나이트 후 필수 1일 휴무"(Q2)를 지키면 나데·나이는 자동으로 막혀요. **이데(E → D)만 남은 질문**이에요.

### Q5. 연속 근무일 최대 일수 ✅

- **지금 이해**: "연속 근무와 휴식 규칙이 있다"는 것만 들었어요.
- **근거**: 법 근거는 없고, 현장에서는 보통 5일 이하로 잡아요.
- **질문**: 쉬는 날 없이 최대 며칠까지 연속 근무시키나요?
- **답변** (10-12): 약 **5일**이에요.
- **반영 방향**: 연속 근무 5일 이하. "약"이라고 했으니 병동별로 바꿀 수 있는 값으로 둬요.

### Q6. 주휴일 ✅

- **지금 이해**: 명세서에서 결정을 미뤄 뒀어요 (D-07).
- **근거**: 근로기준법 §55①은 **1주에 평균 1회 이상 유급휴일**을 보장하라고 해요.
- **질문**: 매주 최소 1일 OFF를 꼭 지키나요? 아니면 한 달 전체 OFF 개수만 맞추나요?
- **답변** (10-12): 주휴는 **월 4회**만 맞추면 돼요.
- **반영 방향**: "7일마다 1일 OFF" 같은 주 단위 검사는 하지 않고, 월 단위 OFF 개수로 검사해요. 법은 "1주 **평균** 1회"라서 월 4회와 맞아요.

### Q7. 월 OFF 개수 계산 🟡

- **지금 이해**: OFF = **그 달 빨간날 수 + 1** (Q/A 메모: "+1은 생리")
- **근거**: 생리휴가는 근로기준법 §73에 따라 여성이 청구하면 월 1일을 줘요. 법 기준은 무급이에요.
- **질문**
  - 주말 OFF는 따로 주고, 거기에 빨간날 수 + 1을 더하는 건가요?
  - +1은 모든 간호사에게 주나요? (남성 간호사, 신청하지 않은 사람)
  - 예시: 공휴일이 2일인 30일짜리 달이면 한 사람 OFF가 총 며칠인가요?
- **답변** (10-12): **주휴 월 4회 + 해당 월 공휴일 수 + 1**이에요.
  - 예시: 공휴일이 2일인 달이면 4 + 2 + 1 = **7일**
- **남은 질문**: +1은 모든 간호사에게 주나요? (남성 간호사, 신청하지 않은 사람)
- **반영 방향**: 기능명세서 RULE-03 계산식을 `4 + 공휴일 수 + 1`로 바꾸고, D-07은 결정 완료로 처리해요.

### Q8. 차지 간호사 ✅

- **지금 이해**: Q/A 메모 "차지 데이만 고정" → 차지는 D만 근무해요.
- **근거**: 리서치에서는 모든 듀티(특히 N)에 책임자급 1명이 필요하다는 의견이 있었어요.
- **질문**
  - 차지는 데이 고정이 맞나요?
  - E·N에는 책임자 역할을 하는 사람이 따로 필요한가요? 필요하면 어떤 조건인가요? (숙련도 3단계 등)
- **답변** (10-12): 차지는 **고정 역할이 아니라 해당 날짜 근무에 명시**해요.
- **반영 방향**: 기존 이해("차지는 D만")가 틀렸어요.
  - 간호사 정보의 `dutyRole`에서 `CHARGE`를 빼고, **근무표 셀(날짜 × 간호사)에 차지 표시**를 둬요.
  - 명세서의 "CHARGE는 D만 허용"(NUR-04, 6.1 하드 규칙)을 지워야 해요.
- **남은 질문**: 모든 근무(D/E/N)마다 차지가 1명씩 있어야 하나요? 차지를 맡을 수 있는 조건이 있나요? (숙련도 3단계 등)

### Q9. 신입·숙련도 배치 🟡

- **지금 이해**: 신입은 나이트에 혼자 들어가면 안 돼요. 숙련도는 3단계로 바꿔요 (2차 미팅).
  1. 혼자서 근무 불가능
  2. 혼자서 근무 가능
  3. 1단계 간호사를 데리고 근무 가능
- **질문**
  - "1단계가 있는 듀티에는 3단계가 최소 1명 있어야 한다"로 이해하면 되나요?
  - 이 규칙은 나이트만인가요, 모든 듀티인가요?
  - 한 듀티에 1단계를 최대 몇 명까지 넣을 수 있나요?
  - 신입과 프리셉터를 같은 듀티에 꼭 묶어야 하나요?
- **답변** (10-12)
  - 숙련도는 수간호사가 **주관적으로 판단**해요. 대략 총경력 30% + 해당 병동 경력 70% 비중이에요. → 자동 계산하지 않고 수간호사가 직접 입력해요.
  - 프리셉터는 보통 **4~5년차**가 맡아요.
  - **복귀 간호사**는 1인분 간호사로 배치해요. 히스토리를 보고 숙련 그룹이나 프리셉터로 지정할 수 있어야 해요.
  - 간호사 등록에 근무했던 병동 같은 히스토리를 적는 **비고란**이 필요해요.
- **남은 질문**: 위 질문 4개는 아직 답을 못 들었어요.

### Q10. 필요 인원 ❓

- **지금 이해**: 날짜·듀티별 최소 인원을 수간호사가 정해요. 평일·주말·공휴일을 나누는 안을 권장해요 (D-08).
- **질문**
  - 병동 하나에 간호사가 보통 몇 명인가요?
  - D / E / N 각각 최소 몇 명인가요? 주말·공휴일엔 다른가요?
  - 실제 근무표 예시를 받을 수 있을까요? (개인정보는 지우고)
- **답변**: (3차 미팅에서는 안 다뤘어요.) 멘토가 "근무별 인원 수 같은 현실적인 목 데이터"를 요구했으니 **다음 미팅 전에 꼭 물어봐야** 해요.

### Q11. 희망 오프·연차 신청 ✅

- **지금 이해**: 연차는 승인되면 무조건 반영하고, 희망 오프는 가능하면 반영해요.
- **질문**
  - 한 사람이 한 달에 희망 오프를 몇 개까지 신청할 수 있나요?
  - 같은 날 신청이 몰리면 누구를 우선하나요? (연차, 경력, 지난달 미반영자 등)
  - 신청 마감은 보통 언제인가요?
- **답변** (10-12)
  - 시스템으로 개수를 제한하기보다 **사전 구두 협의**로 처리해요. → 월 한도는 두지 않아요(D-14).
  - 신청 마감은 다음 달 근무 작성일 **약 10일 전**이에요.
  - 일반 간호사는 **모바일**로 근무표 확인과 오프 신청을 해요.
- **남은 질문**: 같은 날 신청이 몰릴 때 우선순위 (구두 협의로 정한다면 시스템에선 필요 없을 수도 있어요)

### Q12. 규칙 직접 추가 ✅ (3차 미팅에서 새로 나옴)

- **답변** (10-12): 규칙은 병원마다 다르므로, 사용자가 **화면에서 직접 추가**할 수 있어야 해요. 예: "나이트 3일 후 오프"
- **반영 방향**: 정해진 규칙을 켜고 끄는 지금 방식(RULE-01)만으로는 부족해요. 아래 같은 **규칙 템플릿**에 값을 넣어 추가하는 방식을 설계해야 해요.
  - 패턴 뒤 휴무: "`N`을 [3]일 하면 다음 [1]일 OFF"
  - 연속 상한: "`N`은 최대 [3]일 연속"
  - 금지 전이: "`E` 다음날 `D` 금지"
  - 대상 제한: "[임산부]는 [평일 D]만"

## 이미 확정된 것

미팅에서 다시 물어볼 필요가 없는 내용입니다.

- 3교대 **D / E / N / Off**, 연차는 `AL`로 표시
- 승인된 연차 날짜에는 근무 배정 금지
- 소속 기간 밖 날짜에는 배정 금지
- 휴직(`ON_LEAVE`)·퇴사 간호사는 배정에서 제외
- 숙련도는 수간호사만 볼 수 있음
- 근무표 기본 보기는 월별, 보조로 주간 보기
- 월별 근무표에 **공휴일(빨간 날) 표시** (10-12)
- 수간호사는 **PC 웹**, 일반 간호사는 **모바일** (10-12)
- 나이트 전담(나이트 킵)은 일부 병동에만 있는 제도이고 지원자만 해요. 1차 출시 범위에서 제외 (10-12)

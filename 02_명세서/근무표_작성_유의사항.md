# 근무표 작성 유의사항

> 노션 "근무표 작성시 유의사항"(10-27)을 옮겼어요. [클라이언트 미팅 (10-26)](../01_기획/클라이언트_미팅_2026-10-26.md) 이후 자동 생성 알고리즘을 다시 짤 때 기준으로 쓰는 규칙이에요.
>
> [근무규칙.md](근무규칙.md)·[비즈니스로직.md](비즈니스로직.md)와 다른 부분은 이 문서가 더 최근 기준이에요. 확정되면 기능·API 명세서에도 반영해 주세요.

1. 해당 월의 **주말 개수 + 1**만큼 기본 오프
2. 나이트를 **3번** 진행하면 추가로 **오프 2개** 제공
3. **수간호사, 차지 간호사는 주중 5일 데이 근무 고정**
4. 하루 필요 인원 기본값은 **데이 7명 · 이브닝 5명 · 나이트 5명**. 수간호사가 직접 수정할 수 있음
5. **퐁당퐁당 근무 금지**. 퐁당퐁당은 데이-이브닝-데이-이브닝처럼 번갈아 반복되는 살인적인 스케줄을 말함. 데이 5번 연속이나 이브닝 5번 연속 같은 건 가능
6. (인원 구성) 간호사의 1~5점 숙련도를 기반으로 **근무마다 평균 3점**이 되도록 배치
7. 오프 신청 기능은 아직 구현이 안 됨 → **고정 배치**로 처리

## 참고

- 1번은 클라이언트 미팅(10-26)의 "주말 + 공휴일 + 1일"과 공휴일 포함 여부가 달라요. 어느 쪽이 맞는지 확인이 필요해요.

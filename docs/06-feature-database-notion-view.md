# 병동 근무표 기능 데이터베이스

이 문서는 노션 데이터베이스의 빠른 검토용 보기다. 실제 데이터베이스 생성에는 함께 제공된 CSV를 가져온다.

## 노션 속성 설정

| 속성 | 권장 형식 | 용도 |
| --- | --- | --- |
| 기능명 | 제목 | 데이터베이스 기본 제목 |
| 기능 ID | 텍스트 | 고유 식별자 |
| 영역 | 선택 | 인증과 소속, 간호사 관리, 근무 규칙, 근무표, 자동 생성, 신청, 알림, 보안과 감사 |
| 변경 구분 | 선택 | 유지, 수정, 신규, 보완 |
| 우선순위 | 선택 | P1, P2 |
| 문서 상태 | 상태 | 기준안, 검토 중, 확정 |
| 사용자 | 다중 선택 | 기능 사용 주체 |
| 결정 필요 | 체크박스 또는 선택 | 제품 결정이 남은 기능 표시 |
| 검토 메모 | 텍스트 | 회의와 검토 의견 기록 |

## 변경 구분 기준

| 구분 | 의미 |
| --- | --- |
| 유지 | 기존 요구사항의 의미를 유지하고 현재 문서에 전문을 다시 기재 |
| 수정 | 기존 요구사항의 조건이나 처리 방식을 변경 또는 명확화 |
| 신규 | 원문 v0.2에서 신규로 추가했거나 누락 흐름을 새 기능으로 정의 |
| 보완 | 이전 문서의 실제 내용이 없거나 여러 항목에 흩어진 요구사항을 통합 정리 |

## 권장 보기

- 전체 기능은 영역으로 그룹화하고 우선순위와 변경 구분을 표시한다.
- P1 기능은 우선순위가 P1인 항목만 필터링한다.
- 변경 검토는 변경 구분이 수정, 신규 또는 보완인 항목만 표시한다.
- 제품 결정은 결정 필요가 예인 항목과 별도 결정 목록을 함께 검토한다.

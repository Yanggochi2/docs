# 할 일 (2026-10-26)

> 클라이언트 5차 미팅(10-26)을 반영한 팀 작업 계획입니다. 노션(할일 정리(10/19일부터 기록) > 10/26 할일)을 옮겼어요.

## 1. 도메인 규칙 재정립 및 사전 확인 (최우선)

- **노션 및 초기 회의록 재검토**: 기존에 전달받은 근무 제약 조건이 빠진 게 없는지 전부 확인
- **직급 및 역할 체계 명확화**
	- 직급: 수간호사(1명) → 차지 간호사(2명) → 일반 간호사(25명)
	- 프리셉터: 직급이 아닌 '역할(속성)'로 분리 (일반 간호사 중 5~6년 차에 배정)
	- 경력/직급 분리: 직급과 무관하게 연차가 높을 수 있는 구조 반영 (예: 25년 차 일반 간호사, 23년 차 차지 간호사)
- **클라이언트 질의응답(Q&A)**: 일별 D/E/N 최소 필요 인원, 최대 연속 근무일 수 등 알고리즘 상세 조건 즉시 질문 및 확정

## 2. 기능 축소 및 데이터 재구축 (단기)

- **불필요 기능 삭제**
	- 일반 간호사 로그인과 역할별 권한 분기 제거 (수간호사 로그인은 유지, 11-02 팀 확인)
	- 일반 간호사용 온라인 오프 신청 화면 및 API 삭제
	- '다시 짜기(재생성)' 기능 불안정 시 제거
- **데이터 스키마 및 목데이터(총 28명) 개편**
	- 간호사 정보 입력 항목 변경: `입사일` → `입사 연도` (`소속 시작일`은 유지)
	- 28명 세팅: 수간호사 1명, 차지 2명, 일반 25명 (다양한 연차 분포 및 5~6년 차 프리셉터 지정)

## 3. 근무표 자동 생성 알고리즘 재설계 (핵심)

- **고정 근무 및 오프 기준 변경**
	- 차지 간호사: 평일 주 5일 근무 + 주말 휴무로 고정 배치
	- 월 오프 수 산정: 기존 12~13일 임의 배정 폐기 → 주말 + 공휴일 + 1일 기준으로 변경
	- 고정 일정 선반영: 교육일, 학회, 연차, 수간호사가 입력한 오프(종이 달력 신청분) 우선 처리
- **교대 근무 분배 로직 개선**
	- 이브(E)·나이트(N) 세트 묶기 방식 폐기 및 개별 분배
	- 특정 인원(노은서, 권태호 등) 근무 편중 해소 (개인별 근무 횟수 균등화)
	- 기계적인 패턴(이틀 근무-하루 휴무 등) 지양 및 정상적인 연속 근무 패턴 적용

## 4. 화면(UI) 개편 및 수간호사 기능 추가 (병행)

- **근무표 화면 및 정렬 수정**
	- 기본 화면: 진입 시 월간 뷰로 기본 출력
	- 정렬 옵션 단순화 (2개): 숙련도순(기본값) / 이름순
		- 숙련도순: 수간호사 → 차지 간호사 상단 고정 후, 일반 간호사 경력 내림차순 정렬
		- 이름순: 직급 구분 없이 가나다순 정렬
- **수간호사용 간호사 관리 기능**: 간호사 생성(등록) 기능 추가 ('간호사 정보 수정' 폼 재사용)
- **공유 기능 변경**: '공개하기' 버튼을 공유 링크 배포 방식으로 변경 (로그인 없이 누구나 조회만 가능)

## 5. 통합 테스트 및 최종 점검

- **전체 흐름 점검**: `[인원 등록/수정] → [고정 일정 입력] → [근무표 자동 생성] → [정렬 조회] → [공유 링크 배포]` 작동 확인
- **생성 결과 검증**: 차지 간호사 평일 근무 여부, 오프 개수(`주말+공휴일+1`), E/N 균등 배분, 기본 정렬(숙련도순) 적용 여부 최종 확인

# 할 일 (2026-11-02)

> 클라이언트 6차 미팅(11-02)을 반영한 팀 작업 계획입니다. 노션(할일 정리(10/19일부터 기록) > 11/2 할일)을 옮겼어요.

## 1. 버그 수정 (최우선)

- 새 병동이 생성되지 않는 문제 수정
- 자동생성 후 첫 화면이 주간 뷰로 뜨는 문제 수정 (월간 뷰 기본 출력)

## 2. 근무표 화면 개편 (핵심 방향: 근무표 작성에만 집중)

- 근무표 전체를 한 화면에서 볼 수 있도록 레이아웃 정리
- 근무표 외 잡다한 요소 제거
- 잔여 오프 수 표시 추가 (이름 옆 또는 고정 영역)
- 근무 칸 배경색 + 흰색 글자 스타일 시도

## 3. 간호사 관리 기능

- 간호사 추가/삭제 기능
- 간호사 정보 수정 창 신규 구현 (현재 창 자체가 없음)
- 엑셀 일괄 등록: 샘플 양식 다운로드 → 작성 → 업로드 방식

## 4. 근무 규칙 / 알고리즘 수정

- 야간(N) 연속 근무 2일 → 3일로 변경
- 희망 오프 입력 받기
- 7·5·5 기준 초과 시 오프 부여로 기준 준수 (실제로는 8일·10일 연속 근무도 있을 수 있으나, 자동생성이므로 기준 초과 여부는 인지하고 있어야 함)
- 확인 필요: "7·5·5"가 각각 무엇을 뜻하는지 클라이언트에게 재확인

## 5. 성능 개선

- 클라이언트 피드백: 생성 속도가 느려 알고리즘이 아닌 것 같다고 함
- 생성이 오래 걸리는 원인 분석 — 김민서

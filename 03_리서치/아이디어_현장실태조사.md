# 간호사 근무표 자동화 앱

## 1. 문제점

간호사 근무표를 수작업으로 작성할 경우 여러 조건을 동시에 고려해야 해서 작성이 복잡하다.

- 야간근무가 특정 간호사에게 편중될 수 있음
- 야간근무 후 바로 근무하는 등 휴식시간 문제가 발생할 수 있음
- 주말·야간 근무가 공평하게 배분되지 않을 수 있음
- 간호사의 휴가 및 희망 근무를 반영하기 어려움
- 갑작스러운 결원 발생 시 근무표를 다시 수정해야 함
- 병동별 필요한 인원과 간호사별 조건을 동시에 고려하기 어려움

## 2. 서비스 목적

간호사의 근무 조건과 병동의 인력 조건을 입력하면 이를 바탕으로 근무표를 자동으로 생성하고, 관리자가 최종적으로 수정·확정할 수 있도록 한다.

## 3. 핵심 기능

### 간호사 관리

- 간호사 등록
- 직급 및 근무 가능 시간 설정
- 휴가·휴무 등록

### 근무 조건 관리

- 주간 / 저녁 / 야간 근무 설정
- 시간대별 최소 필요 인원 설정
- 연속 근무 제한
- 야간근무 횟수 제한

### 근무표 자동 생성

입력된 조건을 바탕으로 자동으로 근무표를 생성한다.

### 근무표 관리

- 생성된 근무표 확인
- 관리자 수정
- 근무표 확정
- 간호사별 근무 일정 확인

## 4. 기본 아키텍처

```text
사용자
↓
Frontend
↓
Backend API
↓
┌───────────────┐
│ 근무표 관리 │
│ 간호사 관리 │
│ 근무 조건 관리 │
└───────────────┘
↓
자동 근무표 생성 로직

```

## 5. 기술 구성 예시

- Frontend: React / Next.js
- Backend: Spring Boot 또는 FastAPI
- Database: MySQL
- 자동 근무표 생성: Python 기반 최적화 알고리즘
- 배포: AWS

## 6. 핵심

이 서비스에서 가장 중요한 부분은 단순히 근무표를 저장하는 것이 아니라,

**「간호사별 조건 + 병동 인력 조건 + 근무 규칙을 입력 → 조건을 만족하는 근무표를 자동 생성」**

하는 것이다.

# 간호사 근무 실태 조사

## 1. 주요 문제

### 🔄 불규칙한 교대근무

- 3교대 근무로 인해 수면·생활 패턴이 불규칙함
- 데이·이브닝·나이트 간 근무 전환으로 피로 누적
- 커뮤니티에서도 교대근무에 대한 불편이 반복적으로 확인됨

### 👥 인력 부족

- 인력이 부족하면 근무표 작성 자체가 어려움
- 특정 간호사에게 야간·주말·연속근무가 집중될 수 있음
- 인력 부족 상황을 수치로 확인하기 어려움

### 📅 복잡한 근무표 작성

- 희망근무, 연차, OFF, 나이트 간격 등을 동시에 고려해야 함
- 병동마다 근무 규칙이 달라 일괄적인 자동 생성이 어려움
- 기존 자동 생성 서비스도 병동별 세부 조건을 모두 반영하기 어려움

### ⚖️ 근무 편중

- 야간근무·주말근무·연속근무가 특정 인원에게 집중될 가능성
- 단순히 근무표를 만드는 것보다 **공정성과 근무 부담을 분석하는 기능**이 필요

---

## 2. 기존 서비스의 한계

> 기존 서비스는 **근무표 생성·조회·교환**에 집중

하지만 실제 현장에서는

**근무표 생성 → 문제 발견 → 수정**

과정이 중요함.

따라서 단순 근무표 앱이 아닌 **근무표 분석·검증 서비스**로 차별화할 수 있음.

---

## 3. 우리 서비스 방향

### 핵심 아이디어

**「근무표를 만드는 앱」 → 「근무표의 문제를 찾아주는 앱」**

- 🔍 인력 부족 구간 탐지
- ⚖️ 근무 편중 분석
- ⚠️ 연속근무·위험 패턴 탐지
- 🔄 근무 교환 가능 인원 추천
- 💡 문제 발생 시 수정 방향 제안
